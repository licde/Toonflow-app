# 短剧剧本生成全流程引擎 V5.0 · 完整执行手册

> **版本号**：V5.0  
> **规则总数**：257条（已整合全部边界细化与补全）  
> **层级总数**：14层（G / W / B / V / M / S / D / X / I / Y / Z / H / L / A）  
> **适用类型**：古风权谋 · 女性成长 · 强反转 · 慢燃虐恋 · 双强对峙  
> **输出格式**：结构化 JSON 分镜表 + 视觉锁定表 + 道具追踪表 + 单集数据包（Z107-Z110）+ 校验报告（H层）  
> **执行模式**：**串行推进 + 自动触发重算**（任意字段变更后，自动执行“变更识别→规则依赖图查询→受影响规则重算→H层校验→人工确认→Z层数据包更新”的完整闭环）


## 一、输入与解析（启动阶段）

### 1.1 用户输入

| 输入项 | 格式 | 示例 |
|:---|:---|:---|
| 故事核心 | 文本（1-3句） | “一个被当作棋子的女子，在两国博弈中觉醒，成为自己命运的主人。” |
| 世界观设定 | 文本（可选） | “古风权谋，南国北国对峙，血咒规则” |
| 人物设定 | 文本（可选） | “裴青梧（女/22岁/和亲死士）、萧玄策（男/27岁/北国太子）” |
| 风格设定 | 关键词 | “冷峻权谋、女性成长、强反转” |

### 1.2 引擎解析输出

| 输出项 | 说明 |
|:---|:---|
| 一句话内核 | 提取故事核心的“一句话钩子” |
| 三幕结构草案 | 建立/推进/高潮/收尾的粗略分布 |
| 角色弧光草案 | 每个角色的起点→终点 |
| 风格标签清单 | 色彩/光线/音乐/节奏等初始设定 |
| 道具清单草案 | 核心道具及其象征含义 |
| G层锚点草案 | G1-G5的初步设计 |

### 2.4 G层锚点（跨集一致性）

| ID | 名称 | 检查内容 | 每集执行方式 |
|:---|:---|:---|:---|
| G1 | 角色灵魂锚点 | 每集至少1次“主动选择”（最小单位：倒茶/续茶） | 设计1个“选择瞬间” |
| G2 | 世界观规则锚点 | 血咒碑状态每集更新（裂痕程度） | 片头/片尾画面展示 |
| G3 | 调性/风格锚点 | 冷峻底色不变，情感线靠行为推进 | 禁止情感直白台词 |
| G4 | 核心道具锚点 | 匕首/机关鸢/血咒碑/镜/药碗，至少1件出场 | 道具状态逐次升级 |
| G5 | 关系距离锚点 | 每3集更新1次距离值（1-7级） | 输出“关系距离表” |


## 三、分镜设计流程（W → B → V/M/S/D → X/I → Y → Z → H）

### 3.1 W层（编剧设计）· 必填字段

| 字段名 | 说明 | 选项/格式 |
|:---|:---|:---|
| 镜号 | 本镜序号 | 数字 |
| 景别 | 拍摄范围 | 全景/中景/近景/特写/极特写 |
| 时长 | 单镜秒数 | 数字（秒） |
| 画面描述 | 该镜画面内容 | 文本 |
| 台词 | 角色说的原话 | 文本 / 无 |
| 情绪强度 | 1-7级 | 1-7 |
| 节奏分区 | 该镜节奏类型 | fast / medium / slow |
| 台词节奏 | 该句台词的节奏类型 | 快速短句 / 中速陈述 / 慢速重音 / 无 |
| 信息层 | 信息层级 | 表层 / 深层 / 情感 |
| 情绪交付阶 | 情绪交付阶段 | 试探 / 突破 / 交付 / 无 |
| 脱钩设计 | 台词与表演脱钩 | 说A做B / 说A做A- / 无 |
| 道具状态标签 | 道具当前状态 | 安静 / 焦点 / 交互 / 改变 |
| 画面锚点 | 该镜中与台词锁定的画面对象 | 道具 / 空间 / 人 / 动作 |

### 3.2 B层（转化桥）· 自动生成

| 输出项 | 说明 |
|:---|:---|
| 情绪曲线 | 每镜情绪值的逐秒分布（0-75s） |
| 三幕节奏映射 | 第一幕(0-15s):快+极快 / 第二幕(15-55s):中+快+慢 / 第三幕(55-75s):慢+留白 |
| 信息联动链 | 每集信息的“因果锁链”（每条信息承接上一条、引出下一条） |
| 对话模式判定 | 本集对话属于哪类模式（追问式/重复验证式/沉默推进式） |
| 独白/旁白判定 | 本集是否使用独白或旁白，及其类型 |

### 3.3 V/M/S/D层（执行/视听/细节/资产）· 自动填充

| 输出项 | 说明 |
|:---|:---|
| V层 | 钩子密度、前3秒定调、结尾钩子、信息密度检测 |
| M层 | 情绪→机位运动绑定（情绪5→手持+跟拍） |
| S层 | 色温区间（冷/暖/混合）、光质（硬/柔/混合）、构图规则 |
| D层 | 场景资产卡片、道具资产卡片、道具状态追踪表 |

### 3.4 X/I层（扩展/实现）· 自动生成

| 输出项 | 说明 |
|:---|:---|
| 切镜节奏曲线 | fast/medium/slow的分布、连续时长校验 |
| 运动衔接 | 每个镜头的机位运动方式 |
| 呼吸感校验 | 连续同节奏≥3镜后是否插入对照节奏 |
| 场景切换理由 | 每次场景切换标注“切换理由”（空间/时间/情绪/信息） |

### 3.5 Y层（提示词穿透）· 自动生成

#### 3.5.1 imagePrompt生成规则

| 固定包含项 | 格式示例 |
|:---|:---|
| 角色弧光状态 | `裴青梧·认命期` |
| 情绪/表演词 | `情绪5, 面无表情但手在抖` |
| 色温/光质 | `4500K暗蓝光质` |
| 道具状态 | `匕首藏枕下（安静→焦点）` |
| 景别/机位 | `特写, 正面平视` |
| 构图关键词 | `f/2.8浅景深` |

#### 3.5.2 videoPrompt生成规则

| 固定包含项 | 格式示例 |
|:---|:---|
| 镜头运动 | `手持缓慢推进` |
| 时长 | `3s` |
| 焦点位置 | `focus on 手` |
| 特殊动作 | `台词后停顿1s` |

#### 3.5.3 audioPrompt生成规则

| 固定包含项 | 格式示例 |
|:---|:---|
| 台词交付方式 | `慢速重音，停顿1s，发抖` |
| BGM情绪 | `单音持续低音(冷)` |
| 音效 | `布料摩擦(松手)` |
| 留白 | `交付后留白2s` |

#### 3.5.4 台词→提示词映射表（Y59-Y74）

| 台词类型 | imagePrompt强化 | videoPrompt强化 | audioPrompt强化 |
|:---|:---|:---|:---|
| 快速短句 | `sharp eye contact, urgent` | `quick cut, 0.5s reaction` | `quick breath, abrupt cut` |
| 慢速重音 | `paused expression, frozen` | `slow push in, hold pause` | `slow delivery, 1s silence` |
| 脱钩表演 | `mismatched expression/action` | `focus on hands while dialogue plays` | `dialogue steady, ambient shifts` |
| 画外旁白 | `wide shot, anchor visible` | `wide hold 3s, slow push` | `voice over, clear, low volume` |
| 内心独白 | `close-up, contemplative` | `slow push, focus on eyes` | `breathy/near, minimal reverb` |
| 字幕交代 | `text overlay on frame` | `wide hold 2.5s, text overlay` | `no audio, text only` |

### 3.6 Z层（制作执行）· 数据打包

每集输出包含以下数据包：
- **Z107**：完整分镜JSON（含全部字段）
- **Z108**：全镜imagePrompt + videoPrompt
- **Z109**：全镜台词/独白/旁白文本 + BGM/音效标注
- **Z110**：关键帧预览图描述（可选）

### 3.7 H层（交叉校验）· 强制执行

#### 3.7.1 H3层（台词专属校验）

| 规则ID | 检查内容 | 通过标准 |
|:---|:---|:---|
| H3-1 | 因果链步数 | ≤2步 |
| H3-2 | 承接/引出对象 | 必须在前后5镜内出现 |
| H3-3 | 因果堆砌检测 | 触发→回应→闭环，≤3句 |
| H3-4 | 台词爆发点→脱钩强制 | emotion≥6的台词必须同时标注脱钩表演 |
| H3-5 | 台词锁定画面强制 | 深层信息台词必须标注画面锚点 |
| H3-6 | 情绪交付完整性 | 共情时刻必须达到“交付”阶 |
| H3-7 | 道具状态联动强制 | 反转点必须伴随道具状态变化 |

#### 3.7.2 H4层（系统校验）

| 规则ID | 检查内容 | 通过标准 |
|:---|:---|:---|
| H4-1 | 情绪恢复完整性 | 情绪≥6后必须跟缓冲→平复→重建三阶段 |
| H4-2 | 时长-情绪一致性 | 情绪≥5的镜，时长必须≥3s |
| H4-3 | 连续节奏呼吸感 | 连续同节奏≥3镜后必须插入对照节奏镜 |
| H4-4 | 台词-镜数匹配 | 台词≥3句的段，对应镜数必须≥台词数×0.8 |
| H4-5 | 台词密度自动检测 | 每10秒20-50字，单句情绪≥5时≤12字 |
| H4-6 | 独白规则检查 | 独白≤2句/次，≤8字/句，仅用于内心状态/决策 |
| H4-7 | 沉默规则检查 | 信息/权力/情感沉默类型必须匹配位置/动作/时长 |
| H4-8 | 多角色对话检查 | 3人以上场景，不说话角色必须持续有微动作 |
| H4-9 | BGM情绪冲突检查 | 冲突时由道具状态主持张力 |
| H4-10 | 信息排列顺序检查 | 反转场景先揭谜底后给背景；共情场景先给背景后揭谜底 |
| H4-11 | 道具僵化检测 | 道具状态连续3句以上未变化 → 警告 |

#### 3.7.3 H2层（系统校验）

| 规则ID | 检查内容 | 通过标准 |
|:---|:---|:---|
| H2-1 | 情绪曲线与分镜一致性 | 所有峰谷对应分镜有效 |
| H2-2 | 信息密度与分镜一致性 | 每10秒≥1条联动信息 |
| H2-3 | G层锚点覆盖 | G1-G5全部执行 |


## 四、自动触发流程（已整合）

### 4.1 触发原则

**“任意字段变更 → 自动识别受影响规则 → 重算 → 校验 → 数据包更新”**

### 4.2 五维覆盖

| 维度 | 触发字段 | 自动重算规则 | 校验规则 |
|:---|:---|:---|:---|
| **文字类** | 台词文本/节奏/独白标记/长度/接话速度 | W71-W77系列 + B层 + Y59-Y65 | H3-1至H3-7 + H4-5 |
| **视觉类** | 画面描述/景别/道具/色温/站位 | V层 + D层 + S层 + X层 + Y层 | H4-11 + H3-5 |
| **情绪类** | 情绪值/交付阶/曲线 | B层 + M层 + I层 + S层 + Y65 | H2-1 + H4-2 |
| **故事类** | 剧情节点/角色弧光/关系值/反转点 | G层 + W层 + B层 + I层 | H2-3 + H3-7 |
| **风格类** | 风格基调/BGM/光质 | G3 + S层 + Y66 + I层 | H4-9 + H4-11 |

### 4.3 执行步骤（修改后强制执行）

```
1. 变更识别 → 输出“本次修改字段清单”
2. 规则依赖图查询 → 输出“受影响规则列表”
3. 自动重算 → 输出“新旧对比表”
4. H层校验 → 输出“通过/未通过 + 建议修正”
5. 人工确认 → 采纳/不采纳建议
6. Z层数据包更新 → 输出最新版Z107-Z110
```
