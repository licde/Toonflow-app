# P0 源材料预检

对小说/梗概/口述情节做**六维度评分**，输出问题清单与改造方向。BLOCK 未过不得进入 P0.3。

## 输入

- 源材料全文或章节范围（使用 `get_novel_text` / `get_novel_events` 读取）
- 可选：用户指定的改编目标受众

## 六维度评分（P1–P6）

| 维度 | 规则 ID | 评分 1–10 | 量化参考 |
|------|---------|-----------|----------|
| 情绪支撑度 | P1 | 必填 | 情绪高点数量、峰值间隔 |
| 反转密度 | P2 | 必填 | 有效反转数 / 章节数 |
| 信息密度 | P3 | 必填 | 核心信息释放节奏 |
| 冲突强度 | P4 | 必填 | 不可调和冲突维度数 |
| 人物弧光 | P5 | 必填 | 主角状态变化节点 |
| 台词质量 | P6 | 必填 | 可拍摄对白比例 |

**P7 综合质量等级**：优≥8 / 良≥6 / 中≥4 / 差<4（附判断理由）

## 问题清单（P8–P12）

| 列 | 说明 |
|----|------|
| 问题编号 | P-001 递增 |
| 类型 | 情绪/反转/信息/冲突/弧光/台词 |
| 具体描述 | 定位到段落或场景 |
| 改造建议 | 可执行 |

## 改造方向（P13–P18）

输出 **3 个**改编方向，每个方向须对应 ≥2 个诊断问题。

## 边界条件

- 评分必须基于可量化标准，附段落定位
- 问题清单必须对应具体场景或段落
- 改造方向与诊断问题形成因果关系

## 输出格式

写入 `planData.preCheck`，并输出 XML：

```xml
<preCheck>
  <dimensions>
    <dim id="P1" name="情绪支撑度" score="7" reason="..." />
    ...
  </dimensions>
  <qualityGrade>良</qualityGrade>
  <issues>...</issues>
  <directions>...</directions>
</preCheck>
```

## ruleAudit

- stage: `P0`
- BLOCK 项：六维度均有分、P7 有等级、问题≥1 条或有明确「无重大问题」说明、方向=3
