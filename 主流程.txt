# 短剧剧本生成全流程引擎 V5.0 · 完整闭环 Skill

> **版本**：V5.0
> **规则总数**：297条（含前期改编全流程）
> **层级总数**：14层（P/G/W/B/V/M/S/D/X/I/Y/Z/H/L）
> **覆盖范围**：源材料预检 → 改编矩阵决策 → 故事核心构建 → 后检加固 → 角色资产 → 分镜设计 → 视听执行 → 提示词穿透 → 校验反馈
> **执行模式**：串行推进 + 自动触发重算 + 闭环反馈

## 二、前期改编流程（步骤0-0.9）

### 步骤0：旧剧本预检（诊断）

| 字段 | 说明 | 输出格式 |
|:---|:---|:---|
| 输入 | 用户提供的源材料（小说/梗概/口述情节） | — |
| 执行动作 | 六维度评分 + 问题清单 + 改造方向建议 | Markdown报告 |
| 六维度 | 情绪支撑度/反转密度/信息密度/冲突强度/人物弧光/台词质量 | 每项1-10分 |
| 问题清单 | 问题编号/类型/具体描述/改造建议 | 表格 |
| 综合质量等级 | 优/良/中/差 | 判断理由 |
| 改造方向建议 | 基于诊断结果推荐改编方向 | 3个方向 |

**边界条件**：
- 评分必须基于可量化的标准（如情绪高点数量、反转铺垫数量）
- 问题清单必须对应到具体场景或段落
- 改造方向必须与诊断问题形成因果关系

### 步骤0.3：改编矩阵决策

| 字段 | 说明 | 输出格式 |
|:---|:---|:---|
| 输入 | 步骤0诊断报告 + 用户选择的方向 | — |
| 执行动作 | 诊断问题-改编方案映射 + 12维改编矩阵 | Markdown报告 |
| 诊断-方案映射 | 每个诊断问题对应一个改编维度 | 表格 |
| 12维改编矩阵 | 性别结构/场景结构/人物锚点/关系网络/情感逻辑/冲突设计/视觉风格/叙事结构/核心道具/台词策略/音乐氛围/节奏规划 | 每项含A/B/C/D选项+推荐标注 |

**边界条件**：
- 每个改编维度必须标注解决的具体诊断问题
- 推荐配置必须有明确的逻辑理由

### 步骤0.6：改编后故事核心构建

| 字段 | 说明 | 输出格式 |
|:---|:---|:---|
| 输入 | 源材料 + 改编配置 | — |
| 执行动作 | 新叙事内核 + 新人物锚点 + 新关系架构 + 新核心事件序列 + 改编改动日志 | Markdown报告 |
| 新叙事内核 | 一句话故事核心 | 文本 |
| 新人物锚点 | 角色/核心矛盾/初始状态/终局状态 | 表格 |
| 新关系架构 | 角色关系图或表 | 表格/图示 |
| 新核心事件序列 | 阶段/集数/核心事件/对应旧问题解决 | 表格 |
| 改编改动日志 | 改动项/旧内容/新内容/改动原因 | 表格 |

**边界条件**：
- 新故事必须解决步骤0中识别的问题（至少80%覆盖）
- 改动日志必须记录每一项修改的因果逻辑

### 步骤0.8：改编后剧本后检

| 字段 | 说明 | 输出格式 |
|:---|:---|:---|
| 输入 | 改编后的故事框架 | — |
| 执行动作 | 改编前后对比 + 新故事六维度再评分 + 残留问题诊断 | Markdown报告 |
| 改编前后对比 | 旧问题/在新故事中是否解决/说明 | 表格 |
| 六维度再评分 | 维度/评分/对比旧评分/状态 | 表格 |
| 残留问题 | 问题/具体描述/建议加固方向 | 表格 |
| 后检结论 | 通过/有残留问题需加固/需要重新改编 | 判断 |

**边界条件**：
- 六维度评分必须≥5分才算通过
- 残留问题必须给出具体加固方向

### 步骤0.9：改编后剧本加固

| 字段 | 说明 | 输出格式 |
|:---|:---|:---|
| 输入 | 改编后故事框架 + 后检问题清单 | — |
| 执行动作 | 加固执行 + 加固改动日志 + 加固后验证 | Markdown报告 |
| 加固执行 | 问题/加固措施/执行规则 | 表格 |
| 加固改动日志 | 改动项/原内容/新内容 | 表格 |
| 加固后验证 | 维度/加固前评分/加固后评分/变化 | 表格 |
| 结论 | 所有维度≥5分通过 | 判断 |

**边界条件**：
- 加固措施必须引用具体规则ID（W77-B8等）
- 加固后验证必须显示评分变化


## 三、14层详细规则定义（含边界）

### 3.1 P层（产品策划与预检）— 18条

| ID | 名称 | 定义 | 触发条件 | 边界条件 |
|:---|:---|:---|:---|:---|
| P1-P6 | 六维度评分 | 情绪支撑度/反转密度/信息密度/冲突强度/人物弧光/台词质量 | 源材料输入时自动触发 | 每项1-10分，需附评分理由 |
| P7 | 综合质量等级 | 优/良/中/差 | 六维度评分完成后自动触发 | 优≥8分/良≥6分/中≥4分/差＜4分 |
| P8-P12 | 问题清单生成 | 自动识别源材料中的问题 | 源材料输入时自动触发 | 问题必须定位到具体段落 |
| P13-P18 | 改造方向建议 | 基于诊断结果推荐3个改编方向 | 问题清单生成后自动触发 | 每个方向必须对应至少2个诊断问题 |

### 3.2 G层（全局记忆锚点）— 5条

| ID | 名称 | 定义 | 触发条件 | 边界条件 |
|:---|:---|:---|:---|:---|
| G1 | 角色灵魂锚点 | 每集展现核心矛盾/主动选择 | 每集生成前加载+生成后检查 | 选择必须可观察；最小单位：倒茶vs续茶 |
| G2 | 世界观规则锚点 | 每集遵守已建立的系统规则 | 每集生成前加载+生成后检查 | 规则状态必须可视觉化；新增规则需≥3集前有暗示 |
| G3 | 调性/风格锚点 | 每集调性配比与全局设定一致 | 每集生成前加载+生成后检查 | 偏差≤10%；风格标签必须可在画面中感知 |
| G4 | 核心道具锚点 | 核心道具在关键节点必须出现 | 每集生成前加载+生成后检查 | 出现率≥80%；每件道具每集至少1次状态变化 |
| G5 | 角色关系锚点 | 核心关系状态变化必须有触发事件 | 每集生成前加载+生成后检查 | 距离值每3集更新1次；变化幅度≥2需有emotion≥5支撑 |

| ID | 名称 | 定义 | 触发条件 | 边界条件 |

| W6-W10 | 情绪高点设计 | 每集至少1个情绪峰值 | 三幕结构确定时自动触发 | 峰值必须≥6；峰值前必须有≥2个铺垫事件 |
| W11-W15 | 信息释放设计 | 核心/辅助/环境信息分布 | 三幕结构确定时自动触发 | 核心信息必须在第3句之内出现 |
| W16-W20 | 反转设计 | 每集至少1个反转点 | 故事核心确定时自动触发 | 反转前必须有≥2个误导路径 |
| W21-W25 | 角色弧光设计 | 每集弧光推进点 | 角色资产确定时自动触发 | 每集至少1个弧光推进点 |
| W26-W30 | 因果链设计 | 事件必须有前因后果 | 剧情节点设计时自动触发 | 每个事件必须有≥1个前因（3集内）和≥1个后果（3集内） |
| W31-W35 | 情感逻辑设计 | 事件影响度×角色敏感度 | 情绪场景设计时自动触发 | 偏差≥2判定为不匹配 |
| W36-W40 | 冲突设计 | 不可调和判定 | 冲突场景设计时自动触发 | 冲突根源≥2个维度同时对立 |
| W41-W46 | 台词因果递进设计 | 每段对话必须形成因果链 | 对话段落生成时自动触发 | 步数≤2；承接/引出对象在前后5镜内 |

### 3.4 B层（转化桥）— 12条

| ID | 名称 | 定义 | 触发条件 | 边界条件 |
|:---|:---|:---|:---|:---|
| B1 | 情绪节拍→情绪曲线表 | 将三幕结构转化为逐秒情绪曲线 | 三幕结构确定时自动触发 | 0-75s逐秒输出；峰谷偏差≤1级 |
| B2 | 情绪值→景别/时长/切换映射 | 自动选择景别、时长、切换方式 | 情绪曲线生成后自动触发 | emotion4→特写/0.8-1.8s/快速切；emotion6→特写/慢放/手持 |
| B3 | 台词→情绪强度映射 | 从台词内容推导情绪值 | 台词文本输入时自动触发 | 短句+疑问句→2-3；陈述句+情感词→4-5；重复+停顿→6-7 |
| B4 | 台词→表演强度映射 | 从台词内容推导表演强度 | 台词文本输入时自动触发 | 疑问句→中；短句+命令→强；情感词+重复→极强 |
| B5 | 人物弧光→镜号标记 | 在分镜中标记弧光蜕变节点 | 关键节点场景生成时自动触发 | 标记：弧光_蜕变/弧光_推进/弧光_收束 |
| B6 | 反转点→分镜标注 | 在分镜中标记反转位置和类型 | 反转场景生成时自动触发 | 类型：认知/情绪/身份；误导路径必须≥2条 |
| B7 | 信息释放→镜号标记 | 标记每条信息等级 | 信息点设计时自动触发 | 等级：核心/辅助/环境；核心信息必须在第3句之内出现 |
| B8 | 关系距离→情绪联动 | 关系距离值自动映射情绪值 | 关系场景生成时自动触发 | 距离1-2→emotion3-4；距离3-5→emotion5-6；距离6-7→emotion4-5 |
| B9 | 角色弧光→台词语气映射 | 弧光阶段自动决定台词语气 | 角色出场时自动触发 | 认命期→短句/无语气词；动摇期→疑问句/犹豫；觉醒期→陈述句/坚定；执棋期→短句/命令式 |
| B10 | 三幕结构→节奏分区映射 | 自动决定节奏分区 | 三幕结构确定时自动触发 | 第一幕0-15s：快+极快；第二幕15-55s：中+快+慢；第三幕55-75s：慢+留白 |
| B11 | 信息阶梯→台词长度映射 | 信息层级自动决定台词长度 | 信息层级确定时自动触发 | 表层≤8字；深层10-15字；情感≤5字（短句收束） |
| B12 | 情绪-节奏联动 | 情绪值与节奏分区的自动匹配 | 情绪曲线确定时自动触发 | emotion≥5→slow或medium；emotion≤4→fast或medium |

### 3.5 V层（基础执行）— 15条

| V6-V10 | 爆款节奏模板 | 单集时长/镜头数/节奏分布 | 分镜生成时自动触发 | 单集2分30秒-3分钟；镜头数≥25；fast≤20s连续 |
| V11-V15 | 平台适配规则 | 竖屏/横屏适配 | 平台类型确定时自动触发 | 竖屏：人物占画面60%以上；横屏：可展示全景 |

### 3.8 D层（场景/道具）— 12条
