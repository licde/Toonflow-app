# 401 鉴权失败

调用 `/api/logs/*` 或 ingest 返回 `401` / `未提供token` / `无效的token`。

## 适用场景

- curl/Python/Go 上报 ingest 失败
- 浏览器 ingest 在 Network 面板显示 401
- 日志中心页面无法加载

## 前置条件

- Toonflow 数据库 `o_setting` 表已配置 `tokenKey`
- 除 `/api/login/login` 外，所有 API 需 JWT（`src/app.ts` 中间件）
- Token 通过 `Authorization: Bearer <jwt>` 或 query `?token=` 传递

## 完整代码

**获取 token：**

```bash
curl -s -X POST http://localhost:10588/api/login/login \
  -H "Content-Type: application/json" \
  -d '{"username":"admin","password":"<your-password>"}' | jq -r '.data.token'
```

将输出设为环境变量：

```bash
export TOONFLOW_TOKEN="<jwt>"
```

**验证鉴权：**

```bash
# 错误：无 header
curl -i http://localhost:10588/api/logs/health
# HTTP 401 {"message":"未提供token"}

# 正确
curl -i http://localhost:10588/api/logs/health \
  -H "Authorization: Bearer $TOONFLOW_TOKEN"
# HTTP 200
```

**Python 常见错误修复：**

```python
# 错误：缺少 Bearer 前缀
headers={"Authorization": TOKEN}

# 正确
headers={"Authorization": f"Bearer {TOKEN}"}
```

**浏览器 `getToken`：**

```typescript
createBrowserReporter({
  ingestUrl: "/api/logs/ingest",
  getToken: () => {
    const t = localStorage.getItem("token");
    if (!t) throw new Error("not logged in");
    return t; // observability-browser 会自动去掉重复 Bearer
  },
});
```

服务器未配置密钥时返回 **444**：`服务器秘钥未配置，请联系管理员`。

## 预期输出

鉴权成功后任意 logs 端点返回 `code: 200` 的 JSON 包装（`src/lib/responseFormat.ts`）。

ingest 成功：`{"code":200,"data":{"accepted":true},"message":"成功"}`。

## FAQ

**Q1：token 刚获取就无效？**  
检查系统时间是否偏差过大；JWT `tokenKey` 是否在管理端被轮换（需重新登录）。

**Q2：Electron 本地请求也要 token 吗？**  
是，与 Web 相同中间件；开发时可先 login 拿 token 写入环境变量供 Sidecar 使用。
