# 短剧工业化设计思路（基础参考，可扩展）

来源：短剧爆款制作/视听手册摘要。本仓将其落为 **可扩展基础层**，不宣称穷尽。

## 设计铁律（进 Playbook）

1. 剧本 = 情绪过山车：极致人设 + 高频冲突 + 连续反转 + 付费卡点  
2. 黄金前 6s / 第一集微循环 + 集末钩  
3. 情绪四供：爽 / 甜 / 虐 / 惊（按题材包配比）  
4. 视听：强刺激优于美学；Speak 镜 static，冲击在 React/扩镜  
5. 拿到剧本立即场次视听打标 → SB 只执行标签  

## 题材档案（pack 参数）

甜宠 / 虐恋 / 战神 / 悬疑 — 见 `data/fixtures/genre_template_packs/`。

## 切镜要点（设计期自检）

视线匹配、动作势能接续、声音先导；跳切制造冲击；五刀流用于身份揭穿等 beat（`five_cut_reveal`）。

## 衍生

手册未覆盖的本剧打法写入 `planData.viralDerivation[]`，可日后升格进 pack。

投流 ROI、真 LUT、实拍工期、成片像素 Edit — 不进本仓闭环。
